# This repo holds Go content only

This repo is the Go half of the DevDays program, the sibling of
`temporal-devdays-ts`, `-python` and `-java`. It takes no content in any other
language, and a Workshop here never names another SDK: whatever the learner is
writing today is the whole world of the material in front of them.

## Considered Options

A single polyglot DevDays repo was rejected because every sibling already
splits by language, and their tooling (Sandbox Images, Checks, cost records)
assumes one toolchain per repo.

## Consequences

The one exception is a Workshop where another language is part of the system
being taught, never a comparison.
